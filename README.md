# Bootcamp Android Kotlin — nivel experto

Android nativo con Kotlin y Gradle desde cero hasta producción. 42 semanas x 14 h = 588 h.

| Fase | Semanas | Contenido |
|---|---|---|
| 1 Kotlin | 1-8 | Lenguaje a fondo: null safety, sealed/inline/value classes, genéricos, DSLs, coroutines, Flow, serialization |
| 2 Gradle y build | 9-14 | Kotlin DSL, tasks, configuration cache, version catalogs, multi-módulo, convention plugins, plugins propios, build scans, caché remota |
| 3 Fundamentos Android | 15-20 | Ciclo de vida, manifest, permisos, recursos, Intents, AGP, variantes y flavors, firma |
| 4 UI con Compose | 21-27 | Estado, layouts, Material 3, navegación, animaciones, accesibilidad, rendimiento de recomposición, adaptive |
| 5 Arquitectura y datos | 28-33 | MVVM/MVI, Hilt, Room, DataStore, Retrofit/Ktor, WorkManager, offline-first, modularización |
| 6 Calidad y rendimiento | 34-38 | Tests unitarios, Compose y Espresso, Macrobenchmark, Baseline Profiles, R8, memoria, seguridad |
| 7 Producción | 39-42 | CI/CD, Play Console, AAB, publicación, intro a KMP, capstone |

Prerrequisitos: `bc-linux-commandline`, `bc-github`. Java no es prerrequisito: Kotlin se enseña desde cero.

Versiones: [docs/stack-versions.md](docs/stack-versions.md). Decisión de ritmo: [docs/decision-semanas.md](docs/decision-semanas.md).

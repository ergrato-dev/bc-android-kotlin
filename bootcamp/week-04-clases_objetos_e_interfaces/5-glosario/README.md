# Glosario — Semana 04

| Término | Definición |
| --- | --- |
| **abstract** | Clase o miembro sin implementación completa; obliga a las subclases |
| **Companion object** | Objeto asociado a una clase; lo que en otros lenguajes es `static` |
| **Composición** | Reutilizar comportamiento teniendo otro objeto como propiedad |
| **Constructor primario / secundario** | El de la cabecera de la clase / uno adicional que delega en él |
| **Delegación (`by`)** | Reenviar los métodos de una interfaz a otro objeto |
| **Encapsulación** | Proteger el estado interno y exponer solo operaciones que mantienen las reglas |
| **Extensión** | Función o propiedad añadida a un tipo desde fuera, sin modificarlo |
| **Fábrica** | Función que crea objetos y puede validar o devolver `null` (`parse`) |
| **field** | Campo real que guarda el valor de una propiedad, dentro de `get`/`set` |
| **init** | Bloque que se ejecuta al crear un objeto; sitio para validar |
| **Interfaz** | Contrato de lo que algo sabe hacer, sin estado |
| **Invariante** | Condición que un objeto debe cumplir siempre |
| **internal** | Visible dentro del mismo módulo Gradle |
| **lateinit** | Propiedad no nula que se inicializa después |
| **object** | Declaración de un único objeto en todo el programa |
| **open** | Permite heredar una clase o sobrescribir un miembro |
| **override** | Sustituye un miembro heredado o implementa uno abstracto |
| **Polimorfismo** | Un mismo mensaje con comportamientos distintos según el objeto |
| **Propiedad calculada** | Propiedad sin campo cuyo valor se obtiene en cada lectura |
| **Propiedad de respaldo** | Propiedad privada mutable detrás de una vista pública de solo lectura |
| **Smart cast** | Tras `is`, el compilador trata el valor con el tipo comprobado |

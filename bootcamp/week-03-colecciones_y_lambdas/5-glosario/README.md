# Glosario — Semana 03

| Término | Definición |
| --- | --- |
| **also / apply / let / run / with** | Funciones de ámbito: ejecutan un bloque sobre un objeto |
| **associateWith** | Crea un mapa elemento → valor calculado |
| **Closure** | Lambda que captura y recuerda variables de su entorno |
| **Colección de solo lectura** | Sin `add`/`remove` en su tipo (`List`, `Set`, `Map`) |
| **Comparador** | Regla de orden entre dos elementos (`compareBy`, `thenBy`) |
| **Desestructuración** | `val (a, b) = par`: sacar los componentes en variables |
| **fold** | Resume una colección acumulando desde un valor inicial |
| **Función de orden superior** | Función que recibe o devuelve otra función |
| **groupBy** | Agrupa los elementos en un `Map` según una clave calculada |
| **it** | Nombre implícito del único parámetro de una lambda |
| **Lambda** | Función anónima: `{ x -> x * 2 }` |
| **List / Set / Map** | Secuencia con orden / sin repetidos / clave → valor |
| **Mutable** | Colección que admite cambios (`MutableList`, ...) |
| **Operación terminal** | La que dispara el cálculo de una `Sequence` (`toList`, `first`...) |
| **Pair / Triple** | Dos o tres valores juntos |
| **partition** | Divide una colección en dos según un predicado |
| **Perezoso (lazy)** | Calculado solo cuando hace falta |
| **Pipeline** | Cadena de transformaciones sobre una colección |
| **Predicado** | Función que devuelve `Boolean` |
| **Sequence** | Colección evaluada de forma perezosa, elemento a elemento |
| **Tipo de función** | `(A, B) -> C`: el tipo de una lambda |

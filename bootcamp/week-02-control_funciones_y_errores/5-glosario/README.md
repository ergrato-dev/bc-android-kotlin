# Glosario — Semana 02

| Término | Definición |
| --- | --- |
| **Argumento con nombre** | Llamar a una función indicando el nombre del parámetro: `level(12.0, highFrom = 20.0)` |
| **assertFailsWith** | Aserción que comprueba que un bloque lanza una excepción de un tipo dado |
| **break / continue** | Salir del bucle / saltar a la siguiente vuelta |
| **check** | Valida el estado; lanza `IllegalStateException` |
| **Cortocircuito** | `&&` y `\|\|` dejan de evaluar en cuanto conocen el resultado |
| **Cuerpo de expresión** | Función escrita con `=` en vez de `{ }` |
| **Excepción** | Objeto lanzado con `throw` que sube por la pila hasta un `catch` |
| **Exhaustivo** | Un `when` que cubre todos los casos posibles |
| **Expresión / sentencia** | Lo que produce un valor / lo que solo hace algo |
| **finally** | Bloque de `try` que se ejecuta siempre |
| **Nothing** | Tipo de lo que nunca termina con normalidad (`throw`, `TODO()`) |
| **Pila de llamadas** | Cadena de funciones activas; la traza de un error la muestra |
| **Rango** | Secuencia de valores como `1..5`; también `until`, `downTo`, `step` |
| **require** | Valida los argumentos; lanza `IllegalArgumentException` |
| **Result** | Tipo que representa éxito o fallo como valor |
| **runCatching** | Ejecuta un bloque y devuelve un `Result` |
| **Unit** | Tipo de retorno de una función que no devuelve nada útil |
| **Valor por defecto** | Valor que toma un parámetro cuando no se pasa |
| **vararg** | Parámetro que recibe un número variable de argumentos |
| **when** | Selección de varias ramas; es una expresión |
